# layout/

Shell visual de la app: header, sidebar, footer y el contenedor de rutas.

**Customizable por tenant:** el layout **lee un modelo de configuración por tenant** (signals)
— logo, formato de login, visibilidad/orden de header/sidebar/footer y demás opciones — en vez
de hardcodear. Ver `Docs/fwk-notes.md` → "Theming y layout por tenant".
